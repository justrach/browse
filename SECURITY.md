# Security

If you find a security problem in browse, please report it privately:
[**Report a vulnerability**](https://github.com/justrach/browse/security/advisories/new).
Only the maintainers see it.

Please include what you found, how to reproduce it, and what it lets someone
do. We'll answer, fix it, and credit you in the changelog unless you'd rather
we didn't.

Bugs that aren't security problems go in an
[issue](https://github.com/justrach/browse/issues). Problems in the Codegraff
agent itself belong to [justrach/codegraff](https://github.com/justrach/codegraff).
